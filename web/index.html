03 Inspect & export

Save the measured route first. A waypoint file also needs an explicit planned home. Its altitude is above mean sea level (AMSL).

Prepare a QGC WPL 110 waypoint file

The first row is planned-home metadata in QGroundControl. Route rows use altitude relative to home. No terrain, geoid, or ellipsoid conversion occurs.

This is an open route. Home connectors, takeoff, landing, RTL, speed commands, and camera triggers are not included. Waypoint acceptance remains vehicle-specific.
